# Class 3: suggested links

### Dictionaries, objects, libraries

* Practical Python Programming: [tuples and dicts](https://dabeaz-course.github.io/practical-python/Notes/02_Working_with_data/01_Datatypes.html), [classes](https://dabeaz-course.github.io/practical-python/Notes/04_Classes_objects/01_Class.html), [`__repr__` and special methods](https://dabeaz-course.github.io/practical-python/Notes/04_Classes_objects/03_Special_methods.html), [modules](https://dabeaz-course.github.io/practical-python/Notes/03_Program_organization/04_Modules.html) -- "any Python source file is a module."
* [Hash table](https://en.wikipedia.org/wiki/Hash_table) (Wikipedia) -- phone-book diagram at top; why lookup by name is fast. [Associative array](https://en.wikipedia.org/wiki/Associative_array) is the concept page.
* [Object oriented](https://technically.dev/universe/object-oriented) (Technically glossary) -- "an object is a 'thing' that can hold data and do stuff, and you can create many of." One paragraph.
* Technically glossary: [open source](https://technically.dev/universe/open-source), [package registry](https://technically.dev/universe/package-registry) -- what PyPI is.
* [Modules](https://docs.python.org/3/tutorial/modules.html) (official tutorial) -- `import`, module, package. First third.
* [Python Package Index](https://en.wikipedia.org/wiki/Python_Package_Index) (Wikipedia) -- where `pip install` gets things.
* Automate the Boring Stuff, 3rd ed.: [Dictionaries and Structuring Data](https://automatetheboringstuff.com/3e/chapter7.html), [Appendix A: Installing Third-Party Packages](https://automatetheboringstuff.com/3e/appendixa.html).

### git

* [What's version control and GitHub?](https://technically.dev/posts/whats-version-control-and-github) (Technically) -- `presentation_final_final_2.pptx` analogy. Gated after the "GitHub and hosting" section; the free part covers the concepts. Glossary entries are ungated: [version control](https://technically.dev/universe/version-control), [branch](https://technically.dev/universe/branch), [pull request](https://technically.dev/universe/pull-request), [merging](https://technically.dev/universe/merging).
* [About Git](https://docs.github.com/en/get-started/using-git/about-git) (GitHub docs) -- commits as snapshots; git vs GitHub. Front half.
* [Hello World](https://docs.github.com/get-started/quickstart/hello-world) (GitHub quickstart) -- repo, branch, commit, pull request by clicking. "You don't need to know how to code." Needs a free GitHub account.
* [Learn Git Branching](https://learngitbranching.js.org/) -- interactive; commits and branches drawn as a tree. Intro sequence only.
* [Oh Shit, Git!?!](https://ohshitgit.com/) (Katie Sylor-Miller) -- for after the first mistake; shows history is recoverable. Clean-language copy at [dangitgit.com](https://dangitgit.com/).
* [git cheat sheet](https://wizardzines.com/comics/git-cheat-sheet/) (Julia Evans comic) -- one page, poster-style.
* [Git](https://en.wikipedia.org/wiki/Git) (Wikipedia) -- reference; lead assumes a little context.

### LLMs and agents

* [Large Language Models explained briefly](https://www.youtube.com/watch?v=WMcwoIyK4DA) (3Blue1Brown) -- 7 min, animated, next-token prediction. Best single item.
* Technically glossary: [LLM](https://technically.dev/universe/llm), [AI agent](https://technically.dev/universe/ai-agent) ("a chatbot answers and stops; an agent keeps going until the job is done"), [harness](https://technically.dev/universe/harness), [training](https://technically.dev/universe/training), [pre-training](https://technically.dev/universe/pre-training), [post-training](https://technically.dev/universe/post-training), [model weights](https://technically.dev/universe/model-weights).
* [I think "agent" may finally have a widely enough agreed upon definition](https://simonw.substack.com/p/i-think-agent-may-finally-have-a) (Simon Willison) -- "an LLM agent runs tools in a loop to achieve a goal." 6 min.
* [Tiktokenizer](https://tiktokenizer.vercel.app/) -- type text, see the tokens. No login. (OpenAI's [tokenizer page](https://platform.openai.com/tokenizer) is the same demo; it blocked my fetch, so unverified.)
* [Large language model](https://en.wikipedia.org/wiki/Large_language_model), [Hallucination (AI)](https://en.wikipedia.org/wiki/Hallucination_(artificial_intelligence)) (Wikipedia) -- references; hallucination page's examples are clearer than its lead.
* [But what is a GPT?](https://www.youtube.com/watch?v=yMQPQuz5WpA) (3Blue1Brown) -- 27 min, going deeper; first half covers tokens and embeddings.
* Skipped: Karpathy's 1-hour intro (too long), Anthropic "Building Effective Agents" (for engineers).
