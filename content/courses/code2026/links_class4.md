# Class 4: suggested links

Checked 2026-09-18. Bullets are in index.md style; copy what you want. "(research.md)" = already in your research notes.

### Files, network, scraping

* Automate the Boring Stuff, 3rd ed.: [Reading and Writing Files](https://automatetheboringstuff.com/3e/chapter10.html) (paths, `with`), [CSV, JSON, and XML](https://automatetheboringstuff.com/3e/chapter18.html), [Web Scraping](https://automatetheboringstuff.com/3e/chapter13.html).
* [What is a URL?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Howto/Web_mechanics/What_is_a_URL) (MDN) -- postal-address analogy; the parts of a URL.
* [An overview of HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) (MDN) -- request, response, status code.
* [Anatomy of an HTTP request](https://wizardzines.com/comics/anatomy-http-request/) (Julia Evans comic) -- one page, a real GET and POST labelled.
* [http.cat](https://http.cat/) -- a cat per status code. [List of HTTP status codes](https://en.wikipedia.org/wiki/List_of_HTTP_status_codes) (Wikipedia) for the reference.
* [robots.txt](https://en.wikipedia.org/wiki/Robots.txt), [Web scraping](https://en.wikipedia.org/wiki/Web_scraping) (Wikipedia) -- a request, not a lock.
* [JSON](https://en.wikipedia.org/wiki/JSON), [Comma-separated values](https://en.wikipedia.org/wiki/Comma-separated_values), [Character encoding](https://en.wikipedia.org/wiki/Character_encoding) (Wikipedia) -- text is bytes plus a convention.
* Technically glossary: [HTTP](https://technically.dev/universe/http), [scrape](https://technically.dev/universe/scrape), [IP address](https://technically.dev/universe/ip-address), [DNS](https://technically.dev/universe/dns).
* (research.md) [Chrome DevTools: view and change the DOM](https://developer.chrome.com/docs/devtools/dom) -- the "Inspect" section: a page is a tree.

### Other languages

* [FizzBuzz](https://rosettacode.org/wiki/FizzBuzz) (Rosetta Code) -- the same program in hundreds of languages. Pre-pick five; the page has joke languages too.
* ["Hello, World!" program](https://en.wikipedia.org/wiki/%22Hello,_World!%22_program) (Wikipedia) -- same idea, simpler program, plus history.
* [Programming language](https://en.wikipedia.org/wiki/Programming_language) (Wikipedia) -- reference; "engineered language for expressing computer programs."
* [Compiled language](https://en.wikipedia.org/wiki/Compiled_language), [Interpreter (computing)](https://en.wikipedia.org/wiki/Interpreter_(computing)) (Wikipedia) -- the two together give compiled vs interpreted, and the caveat that it is a property of the implementation.
* Technically glossary: [compile](https://technically.dev/universe/compile) ("translating one thing to another"), [runtime](https://technically.dev/universe/runtime), [script](https://technically.dev/universe/script), [JavaScript](https://technically.dev/universe/javascript).
* [Stack Overflow Developer Survey 2025: Technology](https://survey.stackoverflow.co/2025/technology) -- charts of what people actually use; JavaScript and Python at the top.
* Crash Course Computer Science [#11 The First Programming Languages](https://www.youtube.com/watch?v=RU1u-js7db8), [#12 Programming Basics: Statements & Functions](https://www.youtube.com/watch?v=l26oaHV7D40) -- 11 min each; Grace Hopper and the first compiler. (#11 also fits Class 6 theory.)

### The apps that run our code

* [What is Colaboratory?](https://research.google.com/colaboratory/faq.html) (Colab FAQ) -- "a hosted Jupyter Notebook service that requires no setup." Plain.
* [What is Jupyter?](https://docs.jupyter.org/en/latest/what_is_jupyter.html) (Jupyter docs) -- the "kernel" is the long-running program holding your notebook's data. Just that section.
* [CPython](https://en.wikipedia.org/wiki/CPython) (Wikipedia) -- the program that runs Python; pairs with the CPython repo link already here. Gloss "reference implementation" as "the official one."
* [Read-eval-print loop](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop) (Wikipedia) -- what Shift+Enter does.
* [What is JavaScript?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/What_is_JavaScript) (MDN) -- the browser tab is the runtime; section "What is JavaScript doing on your page?"
* [Integrated development environment](https://en.wikipedia.org/wiki/Integrated_development_environment), [Shell (computing)](https://en.wikipedia.org/wiki/Shell_(computing)), [Xcode](https://en.wikipedia.org/wiki/Xcode) (Wikipedia) -- references.
* Technically glossary: [runtime](https://technically.dev/universe/runtime), [terminal](https://technically.dev/universe/terminal), [macOS/Windows/Linux](https://technically.dev/universe/macos-windows-linux), [iOS/Android](https://technically.dev/universe/ios-android).
* (research.md) [The Unix Shell](https://swcarpentry.github.io/shell-novice/) (Software Carpentry), episodes 1-2 -- what a file, directory, path, and command are.
